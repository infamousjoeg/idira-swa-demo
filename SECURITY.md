# Security Policy

## Supported versions

This is a demo, not a supported product. Use at your own risk; do not
deploy on systems that handle real workloads.

## Reporting a vulnerability

Open a private security advisory:
[Report a vulnerability](https://github.com/infamousjoeg/idira-swa-demo/security/advisories/new).
You can also email <security@example.invalid> (placeholder -- the lead
MUST replace with a real inbox before merging, or strike this line so
only the GitHub advisory path remains).

## Out of scope

- Issues in upstream Idira Secure Workload Access itself. Report
  those to Idira.
- Issues in the bundled demo workload images (`shipper`, `carrier`,
  `portal`) that depend on misconfiguring the demo (e.g., exposing
  the portal to the internet).
